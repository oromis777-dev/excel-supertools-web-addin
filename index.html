ExcelSuperTools Web Add-in

Online (GitHub Pages)

Хостинг веб-надбудови ExcelSuperTools успішно розгорнуто. Усі необхідні файли готові для завантаження в Microsoft Excel.

📥 Завантажити manifest.xml 🖥️ Відкрити Taskpane 📖 Довідка та інструкції

🚀 Як підключити в Excel:

  1. Завантажте manifest.xml за кнопкою вище.
  2. Відкрийте Excel (Online або настільний).
  3. Перейдіть: Вставка → Надбудови (Add-ins) → Мої надбудови → Завантажити мою надбудову (Upload My Add-in).
  4. Виберіть збережений manifest.xml.
